# حساب من

برنامه‌ی وب حسابداری شخصی برای آیفون (PWA)، با ASP.NET Core و SQLite.

- اجرا: `run.bat` و بعد `http://localhost:5080`
- آزمون‌ها: `run-tests.bat`
- مسیر اطلاعات: متغیر `SA_DATA` (پیش‌فرض `data`)
- هر تراکنش ردیف‌های دفتری با جمع صفر می‌سازد؛ مبلغ‌ها عدد صحیح تومان و تاریخ‌ها رشته‌ی شمسی صفرپرند.
- ثبت‌های گوشی با `clientId` یکتا ارسال می‌شوند تا ارسال دوباره تکراری نشود.
- قبل از گذاشتن روی اینترنت: اول کاربر مدیر را بسازید (اولین بازدیدکننده مدیر می‌شود) و HTTPS را فعال کنید.

## نسخه‌ی فقط گوشی (`phone/`)
بدون سرور: همه‌ی منطق در `phone/core.js` است و اطلاعات رمزگذاری‌شده در IndexedDB گوشی می‌ماند. برای نصب، پوشه‌ی `phone` باید یک بار روی یک نشانی HTTPS بارگذاری شود. آزمون‌ها با `node phone/tests.js`. نیاز به iOS 16.4 یا بالاتر.
